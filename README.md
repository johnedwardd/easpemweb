Step by Step initializing StepX Website
1. Download StepX Folder
2. Extract StepX.zip
3. Tempatkan folder StepX didalam folder www Laragon
4. Buka StepX.sql dan jalankan Query didalam laragon
5. Sekarang StepX Website sudah berjalan saat melakukan Start di Laragon dan press button Web
